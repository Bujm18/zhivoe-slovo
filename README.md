# Живое слово

Скилл для [Claude Code](https://claude.com/claude-code): вычитка художественной прозы на русском языке по мотивам книги Норы Галь «Слово живое и мёртвое».

Скилл ищет в тексте канцелярит, пустые и казённые слова, лишние заимствования, неживые реплики, смешанные обороты, слова не к месту и не по тону. По каждому месту он объясняет, что не так, и предлагает варианты. В текст он ничего не вносит: решает автор.

## Что внутри

| Файл | Что в нём |
|---|---|
| `SKILL.md` | 14 правил, порядок работы, формат отчёта по главе |
| `shpargalka.md` | шпаргалка для разбора абзаца |
| `priemy.md` | приёмы правки: когда, как и что проверить после |
| `primery.md` | примеры «было / стало» по каждому правилу |
| `slovar.md` | термины |

## Установка

**Без программ:**

1. Нажмите вверху этой страницы зелёную кнопку **Code** и выберите **Download ZIP**.
2. Распакуйте архив. Получится папка `zhivoe-slovo-main`.
3. Переименуйте её в `zhivoe-slovo`. Внутри неё сразу должен лежать файл `SKILL.md`.
4. Положите папку в одно из мест:
   - `~/.claude/skills/` — скилл будет доступен во всех проектах (в Windows это `C:\Users\<ваше имя>\.claude\skills\`);
   - `.claude/skills/` внутри папки вашей книги — только в этом проекте.

   Если папки `skills` нет, создайте её.
5. Если скилл не появился, перезапустите Claude Code.

**Через git:**

```
git clone https://github.com/Bujm18/zhivoe-slovo ~/.claude/skills/zhivoe-slovo
```

## Как пользоваться

Скилл вызывается только по имени:

```
/zhivoe-slovo <абзац текста>
/zhivoe-slovo <путь к файлу главы>
/zhivoe-slovo деепричастия
```

Чтобы Claude сам предлагал скилл, когда вы просите вычитать текст, уберите из `SKILL.md` строку `disable-model-invocation: true`.

## Откуда это

Метод взят из книги Норы Галь «Слово живое и мёртвое». Текста книги в скилле нет: правила пересказаны своими словами, все примеры придуманы заново. В книге сотни разобранных примеров из живой практики редактора и переводчика. Если скилл вам пригодился, прочитайте книгу.

Скилл сделан для работы над собственным романом и проверен на его главах.
